# Material de apoyo de laboratorios

Esta carpeta contiene el material asociado a los informes de Física Experimental: mediciones, hojas de cálculo, código de análisis, archivos de Tracker, videos, figuras y otros archivos de trabajo.

## Laboratorios documentados

- [`analisis-de-un-movimiento-en-caida-libre`](./analisis-de-un-movimiento-en-caida-libre/) — hojas de cálculo, figuras y documentos complementarios.
- [`lanzamiento-parabolico`](./lanzamiento-parabolico/) — mediciones, archivos de Tracker e imágenes del montaje.
- [`movimiento-aleatorio`](./movimiento-aleatorio/) — conjuntos de datos y resultados de análisis para distintas configuraciones experimentales.
- [`resistencia-del-aire`](./resistencia-del-aire/) — mediciones VCM, archivos procesados y código Python.
- [`caida-libre-en-medios-viscosos`](./caida-libre-en-medios-viscosos/) — póster final, videos, Tracker, datos, código y figuras.
- [`oscilaciones-amortiguadas-y-acopladas`](./oscilaciones-amortiguadas-y-acopladas/) — mediciones, hojas de cálculo y fotografías del montaje.
- [`calibracion-sensores-temperatura`](./calibracion-sensores-temperatura/) — datos de PT100 y manómetro de gas, análisis Python, incertidumbres y regresiones.

Los informes finales correspondientes están en [`../informes/`](../informes/).

Esta colección corresponde a experiencias de laboratorio; los proyectos de desarrollo de mayor alcance se mantienen como carpetas independientes en la raíz del portafolio.
