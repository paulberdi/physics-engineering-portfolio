# Reportes de ejecución

Esta carpeta está reservada para reportes de texto generados por las versiones consolidadas del proyecto.

Los reportes actuales de V1, V2 y V3 se conservan en el OneDrive de trabajo mientras se termina de ordenar el código fuente para su publicación en GitHub.

Los resultados pesados y reproducibles —por ejemplo MP4, GIF y salidas gráficas generadas automáticamente— no se versionarán por defecto. El objetivo del repositorio es conservar el modelo, la documentación y los resultados esenciales sin duplicar archivos que pueden regenerarse ejecutando los scripts.
