# Resultados de simulación

Esta carpeta conserva las salidas **de referencia** producidas durante el proyecto.

- **Datos/**: CSV de comparaciones y experimentos corregidos.
- **Graficos/**: figuras de resultados (correcciones y comparación).
- **Animaciones_MP4/**: fotogramas finales V1–V3 y el archivo MP4 almacenado por partes.
- **registro_ejecucion.json** y **registro_video.json**: metadatos de ejecuciones previas.

Para recuperar el MP4, ejecuta **python reconstruir_multimedia.py** desde la carpeta principal. Para producir datos *nuevos* sin sobrescribir estas referencias, usa [codigo/](../codigo/) y su carpeta de salida predeterminada.
