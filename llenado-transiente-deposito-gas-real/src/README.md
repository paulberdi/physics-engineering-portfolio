# Código fuente

Esta carpeta está reservada para las versiones consolidadas del proyecto computacional ICF130.

El desarrollo actual se mantiene en el OneDrive de trabajo del curso y contiene tres etapas:

1. **V1 — caudal másico constante:** comparación entre gas ideal y Van der Waals bajo llenado adiabático.
2. **V2 — caudal compresible variable:** incorporación de flujo estrangulado y subsónico.
3. **V3 — pared térmica:** incorporación de almacenamiento térmico en la pared y transferencia de calor gas–pared–ambiente.

Los scripts originales no se incluyen todavía en esta carpeta para evitar publicar una estructura incompleta o versiones intermedias con nombres inconsistentes. Cuando se consoliden en GitHub se usarán nombres descriptivos y una interfaz de ejecución coherente.
